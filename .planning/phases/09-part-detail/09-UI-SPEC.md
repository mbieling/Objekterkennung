## Component Inventory

### 1. Back Link

**Element:** `<Link>` (Next.js) styled as inline text link with Lucide `ArrowLeft` icon.

```tsx
// Tailwind classes:
className="flex items-center gap-1 text-sm text-muted-foreground
           hover:text-foreground transition-colors min-h-[44px] mb-6"
```

Behavior: calls `router.back()` if `window.history.length > 1`, else navigates to `/search`.
Label: `← Zurück zur Suche` (ArrowLeft icon 16px + text).

### 2. Main Image

**Element:** `<div>` container + `<img>` or `<Skeleton>`.

```tsx
// Container classes (mobile-first, desktop breakpoint):
className="relative w-[320px] h-[320px] md:w-[480px] md:h-[480px]
           rounded-lg overflow-hidden bg-muted mx-auto mb-3"
```

States:
- **Loading:** `<Skeleton className="w-full h-full" />` — fills container
- **Loaded:** `<img src={selectedUrl} alt={`${name} — Ansicht ${activeIndex + 1}`} className="w-full h-full object-contain" />`
- **Error (img fails):** Keep Skeleton visible, do not crash

`object-contain` (not `object-cover`) — preserves aspect of CAD renders which may have whitespace.

### 3. Thumbnail Strip

**Element:** `<div>` with horizontal overflow scroll.

```tsx
// Strip wrapper:
className="flex gap-2 overflow-x-auto pb-2 mb-6"
// Each thumbnail button:
className="relative w-16 h-16 shrink-0 rounded-md overflow-hidden
           bg-muted cursor-pointer ring-2 ring-transparent
           transition-all focus-visible:ring-ring
           data-[active=true]:ring-primary"
```

States:
- **Loading (no URLs yet):** Render `thumbnail_count` Skeleton items (fallback to 6 if count is 0)
  - `<Skeleton className="w-16 h-16 shrink-0 rounded-md" />`
- **Active thumbnail:** `ring-2 ring-primary` highlight
- **Inactive thumbnail:** `ring-2 ring-transparent`

Behavior: clicking a thumbnail sets it as the active main image. First thumbnail (index 0) is active on initial load.

Note: `thumbnail_count = 0` and `status ≠ 'ready'` → show 6 skeleton items (per D-11).

### 4. Part Name (H1)

```tsx
<h1 className="text-2xl font-semibold leading-tight mb-4">{name}</h1>
```

Matches existing heading style from upload/search pages (`text-2xl font-semibold`).
No truncation — wrap freely (names can be multi-word, mobile width allows wrapping).

### 5. Metadata Block

**Element:** `<dl>` (description list) — semantic HTML for label/value pairs.

```tsx
<dl className="space-y-3 mb-6">
  <div className="flex justify-between items-baseline gap-4">
    <dt className="text-sm text-muted-foreground shrink-0">Teilenummer</dt>
    <dd className="text-sm font-normal text-right">{part_number ?? '—'}</dd>
  </div>
  <div className="flex justify-between items-baseline gap-4">
    <dt className="text-sm text-muted-foreground shrink-0">Projekt</dt>
    <dd className="text-sm font-normal text-right">{project ?? '—'}</dd>
  </div>
  <div className="flex justify-between items-baseline gap-4">
    <dt className="text-sm text-muted-foreground shrink-0">Status</dt>
    <dd><StatusBadge status={status} /></dd>
  </div>
  <div className="flex justify-between items-baseline gap-4">
    <dt className="text-sm text-muted-foreground shrink-0">Hochgeladen</dt>
    <dd className="text-sm font-normal text-right">{formatDate(created_at)}</dd>
  </div>
</dl>
```

Rationale for `<dl>`: semantically correct for label/value metadata, screen-reader friendly.
Rationale against `<table>`: single-column narrow mobile layout doesn't need table grid.

### 6. Status Badge

Reuse the `StatusBadge` pattern from `src/app/admin/CatalogTable.tsx`, adapted for Phase 9 (D-10):

| Status | Badge classes |
|--------|--------------|
| `ready` | `text-green-700 bg-green-50 border-green-200 hover:bg-green-50` |
| `processing` | `variant="outline" className="text-blue-600 border-blue-300"` |
| `pending` | `variant="secondary"` |
| `failed` | `variant="destructive"` |

Note: D-10 specifies amber for "processing" — but the established project pattern in CatalogTable uses blue for `processing` and amber was used for search similarity scores. **Use the existing CatalogTable colors (blue for processing) to maintain visual consistency across the app.** The D-10 amber spec is overridden by the established pattern.

### 7. Date Formatting

```tsx
function formatDate(iso: string): string {
  return new Intl.DateTimeFormat('de-DE', {
    day: '2-digit',
    month: '2-digit',
    year: 'numeric',
  }).format(new Date(iso))
}
```

Output example: `09.05.2026`. Uses `de-DE` locale — consistent with `CatalogTable.tsx` (identical function).

### 8. Download Button

**Element:** shadcn `<Button>` with Lucide `Download` icon (per D-07).

```tsx
// Ready state:
<Button className="w-full gap-2" onClick={handleDownload}>
  <Download className="h-4 w-4" />
  STEP herunterladen
</Button>

// Disabled state (status ≠ 'ready'):
<div className="space-y-2">
  <Button className="w-full gap-2" disabled>
    <Download className="h-4 w-4" />
    STEP herunterladen
  </Button>
  <p className="text-xs text-center text-muted-foreground">
    Datei wird noch verarbeitet
  </p>
</div>
```

`handleDownload`: fetches `GET /api/parts/[id]/download`, receives `{ url, filename }`, sets `window.location.href = url` to trigger browser download (per D-05).

### 9. Loading Skeleton (Full Page)

While the initial `GET /api/parts/[id]` is in flight, render a skeleton layout matching the final structure:

```tsx
// Skeleton layout:
<Skeleton className="h-6 w-32 mb-6" />                    {/* back link */}
<Skeleton className="w-[320px] h-[320px] md:w-[480px] md:h-[480px] rounded-lg mx-auto mb-3" />
<div className="flex gap-2 mb-6">
  {Array.from({ length: 6 }).map((_, i) => (
    <Skeleton key={i} className="w-16 h-16 shrink-0 rounded-md" />
  ))}
</div>
<Skeleton className="h-8 w-3/4 mb-4" />                   {/* H1 */}
<div className="space-y-3 mb-6">
  {Array.from({ length: 4 }).map((_, i) => (
    <Skeleton key={i} className="h-5 w-full" />
  ))}
</div>
<Skeleton className="h-10 w-full" />                       {/* button */}
```

### 10. Error State (Part Not Found / API Failure)

When `GET /api/parts/[id]` returns 404 or network error:

```tsx
<div className="text-center py-16">
  <p className="text-muted-foreground mb-4">Bauteil nicht gefunden.</p>
  <Link href="/search">
    <Button variant="outline">Zurück zur Suche</Button>
  </Link>
</div>
```

## Interaction States

| Component | Trigger | Visual Change |
|-----------|---------|---------------|
| Thumbnail | click | `ring-2 ring-primary` applied, main image swaps |
| Thumbnail | hover | `opacity-80` on image |
| Download button | `status = 'ready'` | Enabled, default primary button |

| Download button | click (ready) | Triggers fetch, then `window.location.href` redirect |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Back link touch target | `min-h-[44px]` — mobile workshop use |

| Download button | `aria-disabled` when disabled, not just `disabled` prop alone |
