**Schritt 3 — /embed-Endpunkt hinzufügen** (nach dem `/enqueue`-Endpunkt, am Ende der Datei):
```python
@app.post("/embed", response_model=EmbedResponse)
def embed(req: EmbedRequest) -> EmbedResponse:
    """Synchroner Embed-Endpunkt — kein Celery, kein Background-Task.

    Nimmt S3-Key entgegen, lädt Bild aus BUCKET_THUMBNAILS,
    berechnet DINOv2 Patch-Mean-Pool Embedding, gibt [768 floats] zurück.
    Das DINOv2-Modell ist bereits als Modul-Global geladen (_model, _processor
    in worker/embedder.py) — kein erneutes AutoModel.from_pretrained() hier.
    """
    logger.info(f"[{req.s3_key}] Embed-Request empfangen")

    s3_client = boto3.client(
        "s3",
        region_name=os.environ["AWS_REGION"],
        aws_access_key_id=os.environ["AWS_ACCESS_KEY_ID"],
        aws_secret_access_key=os.environ["AWS_SECRET_ACCESS_KEY"],
        endpoint_url=os.environ.get("DECOMPOSEDS3_ENDPOINT"),
    )

    with tempfile.NamedTemporaryFile(suffix=".jpg", delete=False) as tmp:
        tmp_path = tmp.name

    try:
        s3_client.download_file(
            os.environ["AWS_S3_BUCKET_THUMBNAILS"],
            req.s3_key,
            tmp_path,
        )
        embedding = get_embedding(tmp_path)  # numpy ndarray (768,)
        logger.info(f"[{req.s3_key}] Embedding berechnet, shape={embedding.shape}")
        return EmbedResponse(embedding=embedding.tolist())
    finally:
        # Lokale Temp-Datei immer löschen — auch bei Fehler (try/finally-Garantie)
        if os.path.exists(tmp_path):
            os.unlink(tmp_path)
```

**Wichtig:** KEIN `status_code=202` — der Endpunkt ist synchron, HTTP 200 ist der Standard. KEIN `process_step_task.delay()` — kein Celery (D-04). Das DINOv2-Modell wird NICHT in dieser Funktion geladen — `get_embedding()` nutzt `_model`/`_processor` aus dem Modul-Scope von `worker/embedder.py`.
